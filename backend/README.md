# Aito Auto Oy – Strapi CMS

See the main README in the project root for setup, content model and deployment.

- `npm run develop` – start with admin auto-reload (content types can be edited)
- `npm run build` – build the admin panel for production
- `npm run start` – start in production mode

Content types: `src/api/*/content-types`, page-builder components: `src/components/sections`, shared components: `src/components/shared`, demo seed: `src/seed`.
